# Notice

aprilfold is built on [aprilcube](https://github.com/younghyopark/aprilcube)
by Younghyo Park, released under the MIT License, starting from aprilcube
0.3.1 (commit `a1dd63e`). The git history of this repository keeps the
original commits and their authorship.

Inherited from aprilcube: marker generation and layout, voxel targets, the
browser designer, robot mounts and the detection and tracking pipeline.

Added in aprilfold: single-color foldable printing (`--mono`), multi-cube
single-color voxel targets, and printed robot twins (`aprilfold twin`).

The aprilcube technical report is not included here; see
[AprilCube: 3D-Printable Fiducial Targets for Reliable 6-DoF Pose Estimation](https://github.com/younghyopark/aprilcube/blob/main/docs/paper.pdf).
